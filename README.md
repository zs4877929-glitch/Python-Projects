# Python-Projects
Python projects built to practice programming concepts and problem-solving skills.

## Projects

### Number Guessing Game
A simple Python game where the user tries to guess a randomly generated number between 1 and 100 within a limited number of attempts.

### Concepts Practiced
- Variables and data types
- User input
- Conditional statements (`if`, `elif`, `else`)
- `while` loops
- `break` statement
- Exception handling (`try` and `except`)
- `random` module
- Type conversion
- Basic problem-solving and program logic
